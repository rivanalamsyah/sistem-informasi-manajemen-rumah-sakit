# Lisensi Penggunaan SIMRS Enterprise

Hak Cipta (c) 2026 RSU Rajawali Citra. Hak Cipta Dilindungi Undang-Undang.

Lisensi Perangkat Lunak SIMRS Enterprise diberikan secara eksklusif untuk operasional pelayanan kesehatan RSU Rajawali Citra dan jaringan mitranya.

Dilarang menyalin, mendistribusikan ulang, atau menjual kembali tanpa izin tertulis dari manajemen RSU Rajawali Citra.

# Pertanyaan Sering Diajukan (FAQ) SIMRS Enterprise

---

### Q1: Apakah SIMRS ini dapat digunakan tanpa koneksi internet (Offline/On-Premise)?
**Jawab**: Ya. SIMRS Enterprise dapat diinstal dan dijalankan 100% pada Local Area Network (LAN) server internal rumah sakit tanpa memerlukan koneksi internet luar.

### Q2: Bagaimana cara menambah user dokter atau perawat baru?
**Jawab**: Masuk sebagai Administrator ➔ Pilih menu **Pengaturan & Reference ➔ Manajemen User** ➔ Klik **Tambah User Baru** ➔ Pilih Role perawat/dokter ➔ Simpan.

### Q3: Apakah laporan keuangan kasir dapat diekspor ke Microsoft Excel?
**Jawab**: Ya. Seluruh laporan pelayanan, EMR, farmasi, lab, billing, dan gudang dapat diekspor langsung ke format `.csv` berenkoding UTF-8 BOM yang dapat langsung dibuka sempurna di Microsoft Excel.
